---
name: tone-check
description: Use to review any user-facing text in StartEase for tone. Finds pressure words, judgment, step counts and diagnosis language.
---
Check the text for:
- Banned words: must, should, need to, have to, overdue, behind, late, failed, lazy, just, simply, easy.
- Any count, number or progress wording about steps.
- Any claim about how the user feels, or any diagnosis or label.
- Text that is long, complex or demanding.
List each problem and suggest a calmer rewrite using plain words.
