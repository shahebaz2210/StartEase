# StartEase product principles (always apply)
- Show exactly ONE step at a time. Never show a list of steps, a step number, a count, a progress bar, or "X left". The API never returns them.
- The app chooses the tool. The user never picks an app. The only option is "I can't use this app".
- Four responses only: Done, Confused, Too big, Not now. One tap, no typing.
- No scores, streaks, points, penalties, or pressure language.
- Never diagnose or label the user. Never claim to know how they feel.
- Not now is a normal choice. Rest is a real screen.
- Academic and professional tasks only. Anything else gets the no-match message, never an error.
- Match the screenshots in design/screens. List any difference in the walkthrough.
- Do not add features that are not in docs/prd.md. Ask first.
